# DevSpace — учебный проект

Проект разделён на две независимые части: React/Vite-клиент и Express API-сервер.

## Структура

- `DevspaceClient/` — React 19 + Vite 6.
- `DevspaceServer/` — Express 4 API, JWT и PostgreSQL.
- Сервер умеет запускаться в демонстрационном режиме без PostgreSQL, если `DATABASE_URL` не задан.

## Запуск сервера

Откройте терминал в папке `DevspaceServer`:

```bash
npm install
```

Для демонстрационного режима можно сразу запустить:

```bash
npm start
```

Для PostgreSQL скопируйте `.env.example` в `.env`, укажите параметры своей базы и затем выполните:

```bash
npm run db:init
npm start
```

**Важно:** `database/seed.sql` содержит команду `TRUNCATE ... RESTART IDENTITY CASCADE`. Команда `npm run db:init` загружает демонстрационные данные и очищает существующие записи в перечисленных таблицах. Не запускайте её на базе с важными данными.

## Запуск клиента

Откройте второй терминал в папке `DevspaceClient`:

```bash
npm install
npm run dev
```

Откройте адрес `http://127.0.0.1:5173`. Vite перенаправляет запросы `/api` на сервер `http://127.0.0.1:3001`.

## Демо-вход

В демонстрационном режиме доступны логины `admin`, `anna`, `ivan`, `maria`; пароль для каждого — `admin`.

Демонстрационный режим хранит изменения в памяти процесса: после перезапуска сервера они сбрасываются.

## Проверка API

Откройте `http://127.0.0.1:3001/api/health`. Сервер должен вернуть статус `ok`.
